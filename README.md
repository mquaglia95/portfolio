# Matthew Quaglia's Personal Portfolio

[www.matthewquaglia.com](https://matthewquaglia.com) - my personal portfolio project, built with React.

## About The Project

This website showcases my professional experience, projects, and contact information in a modern and responsive single-page application.

## Key Features

*   **About Me:** A section with my bio, education, and links.
*   **Projects:** A list of my recent projects with descriptions and links.
*   **Professional Experience:** A timeline of my work experience.
*   **Contact:** My contact information.

## Built With

*   [React](https://reactjs.org/)
*   HTML5
*   CSS3

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You need to have Node.js and npm installed on your machine.

*   npm
    ```sh
    npm install npm@latest -g
    ```

### Installation

1.  Clone the repo
    ```sh
    git clone https://github.com/mquaglia95/portfolio_matthew_quaglia.git
    ```
2.  Install NPM packages
    ```sh
    npm install
    ```

### Running the Application

To run the app in development mode, use the following command:

```sh
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser. The page will reload when you make changes.

## Project Structure

The main files and directories in this project are:

*   `public/index.html`: The main HTML file.
*   `src/index.js`: The entry point of the React application.
*   `src/App.js`: The main application component that contains all the sections of the portfolio.
*   `src/App.css`: The main stylesheet for the application.
*   `src/components/`: This project does not have a dedicated components folder, but custom components like `FireworksBackground.js` are in the `src` folder.
